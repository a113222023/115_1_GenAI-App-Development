
## 1. 作業名稱
同一個App的搜尋證據

## 2. 使用工具
- Python
- Streamlit
- Google Colab
- JSON

## 3. 測試文件
校園讀書交流活動，共4個文字片段。

文件內容包含活動日期、活動時間、活動地點、報名日期、參加人數及活動內容。

## 4. 搜尋模式
使用離線規則示範模式，模型為人工關鍵字4維，非語意模型。

本次沒有使用自己的 Embeddings API，因此真實語意搜尋結果：未測。

## 5. 測試項目
1. 原句搜尋
2. 改寫問題搜尋
3. 文件外問題搜尋
4. top_k=1與top_k=3參數比較
5. 空白問題錯誤測試與重測
6. 兩份JSON搜尋紀錄重新讀回檢查

## 6. 搜尋紀錄
下載兩份search_record.json，並使用第9週9-1程式分別讀回檢查，兩份紀錄皆通過。

## 7. API請求次數
- 自己的API請求：0次
- 離線搜尋：不使用API
- 教師示範：依課程紀錄填寫

## 8. 限制
本次使用人工關鍵字4維的離線規則，不是真正的語意模型，因此改寫問題可能無法找到相關片段。搜尋分數也不能直接代表答案正確，仍需要人工回到原文核對。

## 9. 結論

本次完成同一個Streamlit App的搜尋測試、參數比較、JSON下載與回查，以及錯誤處理測試，了解離線搜尋的功能與限制。
